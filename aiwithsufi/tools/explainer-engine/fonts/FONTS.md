# Engine fonts (all open licence — Google Fonts repo, OFL-1.1 or Apache-2.0)
Use in a project: `<link rel="stylesheet" href="/engine/fonts/fonts.css">`. Note: `document.fonts.ready` only waits for
fonts that something on the page actually uses — X.boot runs after the build, so text created in the build is covered.

| family | weights | good for |
|---|---|---|
| Inter | 100–900 var | SaaS UI, product labels, clean corporate |
| Poppins | 400–800 | geometric friendly SaaS / flat character explainers |
| Montserrat | 100–900 var | bold geometric titles, Kurzgesagt-like headings |
| Nunito / Fredoka | var | rounded, playful (Infographics-style captions, kids) |
| Space Grotesk | 300–700 var | tech / AI launch films |
| Oswald / Bebas Neue / Barlow Condensed | condensed | news/documentary (Vox-like), hype promos, big numbers |
| Archivo Black | 400 | heavy poster type, kinetic promos |
| Playfair Display / DM Serif Display | serif display | editorial, collage, School-of-Life-like titles |
| Libre Baskerville / Lora | serif text | essays, quotes, documents in collage |
| Caveat / Patrick Hand / Permanent Marker | handwriting | annotations over footage, whiteboard, notes |
| Roboto Mono | 100–700 var | code, data, terminal UI |
| Noto Serif SC / Noto Sans SC | 100–900 var | Chinese (Simplified): heavy serif titles, stamp words, bilingual documents |
